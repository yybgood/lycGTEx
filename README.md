# lycGTEx
We built a multi tissue regulatory variant resource for Larimichthys crocea, one of China’s highest production marine aquaculture species. This constitutes the first GTEx style multi tissue xQTL resource for any aquaculture animal. We generated 3.69 Tb of sequencing data, comprising 1,604 RNA seq profiles across seven tissues from 864 individuals, and integrated 127 additional publicly available RNA seq samples. We further assembled GWAS datasets spanning 276 economically important traits, including disease resistance, adaptation to fishmeal free diets and other traits. Using this comprehensive dataset, we mapped regulatory variants across eight tissues. Colocalization analyses prioritized candidate genes at 768 of 1,170 independent GWAS loci (65.64%), illustrating the value of this resource for interpreting trait-associated genetic variation.
